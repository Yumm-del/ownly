> 适用：录屏（1 分钟视频素材）、评委在线体验、现场 demo 前彩排。
> 服务：`python app.py`（默认 127.0.0.1:8765，纯标准库，无需第三方依赖）。

## 官方叙事闭环（每次演示照此走）

```
点击"模拟后台事件到达"（scan）
  ├─ 第一轮：三张守护卡（补货 / 清洁 / 保价）—— 处理掉
  │    （每张卡：证据 chips + 主/次动作；执行后出"完成卡"）
  └─ 第二轮：行程事件到达 → 出发卡（departure_card）
       标题：出差深圳 · 物品就绪检查
       上下文：明天(动态日期) 10:00 · 深圳南山 · 客户提案 / 天气 / 命中数
       清单 4 行：充电器需携带 / 备用充电器应急位（公司工位，不用回家）
                 / 精华无需补货（18% 够用 3 天）/ 防晒建议携带
       动作：生成出差清单（主）/ 出发前再提醒（次）
       执行后：完成卡 + 事件流写入"长期记忆"+"同步 Watch"
再点 scan → 安静（任务只生成一次，处理过不再打扰）
```

设计意图：第一轮证明"守护型 Agent"，第二轮证明 Ownership layer 的独家能力——
**行程到来时 Agent 反查"我拥有什么"替用户做决定**（含双地点记忆：公司工位还有一支）。

## 技术要点（改代码后必读）

- 任务只生成一次的守卫：`storage.has_task_record(item_id, task_type)`（含已完成）。
  重置（/api/reset）清空全部任务与事件后可重演。
- 新组件是 `departure_card`（ui_schema.component），与 `decision_card` 并列；
  前端 `app.js renderTask()` 按 component 分支渲染；样式在 `static/agent-ui.css` 尾部（data-tone="trip"）。
- 行程日期是动态计算的"明天+星期几"，演示永不过期。
- Watch 端（/watch）自动取第一条待处理任务，通用渲染，无需改动。
- 单元测试：`python -m unittest discover -s tests`（10 个用例，含行程到达与防重复）。

## 演示话术骨架（30–45 秒版）

1. "这是我的物品仓——它认识我拥有的每件东西，而且一直在后台守护。"
2. （点 scan）"耳机在保价期内降价了，它带着证据来找我；精华 12 天后用完，它提前提醒。"
3. （处理完，再点 scan）"现在后台收到一个行程——明天深圳提案。"
4. "注意它不是聊天框：它按行程检查了图谱——充电器在家里要带上；**公司工位还有一支备用的**，忘带也不用回家；精华余量 18%，三天够用，不用补。"
5. （点生成清单）"任务完成，结果写进长期记忆，同步到手表。"
6. "Ownly——记住你拥有什么，让你只需决定想做什么。"
